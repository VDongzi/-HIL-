# 什么是HIL测试

A Vector好奇号 animated explainer about hardware-in-the-loop (HIL) testing, built as a single HTML page.

The animation is synced to a recorded narration (`assets/narration.m4a`), and the background music is generated in the browser with the Web Audio API.

## View it

Serve the folder over HTTP, then open the page:

```bash
python -m http.server 8765
```

Open http://localhost:8765/HIL%E6%B5%8B%E8%AF%95%E5%8A%A8%E7%94%BB.html in Chrome and press the space bar to play.

Keyboard shortcuts: F for fullscreen, H to hide the controls, ← and → to step through lines.

The page uses the fonts installed on your computer: Clash Vector, Inter and Noto Sans CJK SC. Without them, the text falls back to other fonts.
